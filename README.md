# Default BIND9 Configuration for Debian

Repositori ini berisi salinan konfigurasi default dari service BIND9 pada sistem operasi Debian.

## Isi Repositori
- `config-bind/` : Salinan berkas dari `/etc/bind/`
- `etc-default/` : Salinan berkas dari `/etc/default/named` atau `/etc/default/bind9`
